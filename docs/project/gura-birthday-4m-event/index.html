Gawr Gura - Birthday & 4M event?

This is a fan-made event for the Virtual YouTuber Gawr Gura, to congrats her Birthday and reach 4M subscribers on YouTube. We have a set of fan-made events to congratulate. In the event, This part that we're studying is part of the website platform for fans to write comments and upload fan artwork.

Graphics style and color tone.

I have created a set of Visual designs to use for the Website, Instagram use, and other print material use. The key direction is simple, fish and sea, and all these elements are also can find in the original character design. The color tones are mainly blue and red as highlights, blue means ocean, and red is fish.
