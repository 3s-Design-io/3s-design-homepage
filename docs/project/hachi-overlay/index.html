Why

Hachi - Stream overlay?

This is a fan-made event for the Virtual YouTuber Hachi, to congrats her on reaching 100k subscribers on YouTube. Hachi's original stream overlay is pretty simple and leaks his own signature. So it is important to insert various key elements in the design. After the overlay is done, I was thinking it might be interesting to also do the loading and the transition too. Then I went to try to learn After Effects, and with a few AE crash reports, the result is pretty good. (As a beginner…)

Graphics style and Color tone.

Hachi’s Art Direction is a Bee theme, in the project I try to use the Honeycomb as the Key Visual to develop the new overlays. For the color tone, I have picked the yellow as main color and black-gray as the secondary color to create contrast. Yellow means Honey and Bees, the gray is Hachi's hair and character design.
