A set of fan-made events to congrats Hoshimachi Suisei's 5th Anniversary & Birthday event. With design of a set of logotype, banner, lightbox, and a Cosplay fan-made MV.

What

Hoshimachi Suisei - 5th Anniversary & Birthday Day Project

When

2023

Why

Suisei 5th & B-Day Project ?

March 22 is the day of our favorite Vtuber Hoshimachi Suisei's Anniversary day & Birthday. To congrats this wonderful day, 3s Design has collaborated with @ Hkvidolfans to create a set of event designs. In this event, 3s Design has a set of event logos, a banner, 2 lightbox ads, and a set of key visuals for the fan-made Stellar Stellar MV.

Graphics style and Color tone.

The core concept of the event logo is simple and elegant. The main part of the event logo is stars because our main character is the Star, and it's her 5th Anniversary so we have put a Star that has orbited 5th time to represent the idea. And it's also her birthday we have also put some Supernova "New star" in the sky.
