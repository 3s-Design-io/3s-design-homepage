Why

Nowa Stream Overlay?

I’m truly honored to have had the opportunity to collaborate with SAWA to design a brand new streaming room and schedule for the AI Vtuber, Nowa! When I first received this invitation, I was genuinely surprised and excited. The theme this time was Cyberpunk, which happens to be one of my favorite genres. I’m extremely grateful to the client for giving me the chance to participate in this project!

Graphics style and Color tone.

For the design style, we chose Cyberpunk as the core, emphasizing a futuristic and mechanical aesthetic, while also incorporating some Y2K elements to soften the vibe and make it feel more approachable and in tune with Nowa's character. For the key visual (KV), we created a set of 12 modular stickers, each representing different features and elements. Some of them even integrate pieces of Nowa's actual source code, making the entire design more distinctive and full of personality!

Stream Overlay

As for the streaming room, in addition to using this modular sticker set, we boldly incorporated a real-time display module that shows Nowa’s backend processes and computations live. This is not only a technical breakthrough but might also be the first time such an interactive design has been implemented in a streaming room!
