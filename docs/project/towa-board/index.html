Tokoyami Towa - Birthday congrats Billboard

This is a fan-made billboard for the Virtual YouTuber Tokoyami Towa, to congrats her birthday. This time we collaborated with a fantastic Taiwanese illustrator(Mr.Lime) to do this project. The theme of this billboard is a mix of APEX and Cyberpunk, to create a story of "APEX new map - Hong Kong". The billboard is located at HK Prince Edward MTR, displayed from 06 Aug to 12 Aug 2022.

Tokoyami Towa - Birthday congrats Billboard?

This is a fan-made billboard for the Virtual YouTuber Tokoyami Towa, to congrats her birthday. This time we collaborated with a fantastic Taiwanese illustrator(Mr.Lime) to do this project. The billboard is located at HK Prince Edward MTR, displayed from 06 Aug to 12 Aug 2022.

Graphics style and Color tone.

The theme of this billboard is a mix of APEX and Cyberpunk, to create a story of "APEX new map - Hong Kong". The main theme we pricked is Cyberpunk and want to make it as cool as it could, but not too crazy. Since the topic theme is cyberpunk, the color tone is also referenced to Cyberpunk yellow and blue to create a strong contrast color. We have another set of colors which is Red-purple and Blue, that color tones are used on another Billboard design.
