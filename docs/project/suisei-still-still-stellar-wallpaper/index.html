Why

Hoshimachi Suisei - “Still Still Stellar” Wallpaper?

This is a set(12+1) of fan-made artwork for the Virtual YouTuber Hoshimachi Suisei, to congrats her on releasing her first Album “Still Still Stellar”. The result is pretty good and I learn a few more Design technic and tricks from it. It is a fun journey.

Graphic styles and Color tones.

The objective of this project is to respect the original Art Direction and to understand each song to create a Key visual of each song and made it as wallpaper. The main graphic style is elegant and high-class modern, both mysterious and attractive. Some of them are mixed with elements of space and stars, which also represent the character's design. The color tones have 2 main sets, black-gold, and blue-white. Combining both of them creates a set of amazing meaningful graphics.
