Mic On - Crowdfunding project?

This is a website Ui Ux design for Mic On - Crowdfunding project. Aim to be young, pop, and smooth style.

Graphics style and Color tone.

Since this is an event website just for explaining the Crowdfunding project details, it contains a lot of information text, and data. It is important to try to make it less informational and make it attractive to keep going and reading on. The color tone is basic on the new Mic On branding and the 3 talents' main color, but the original color is way too strong and bold, the new color set has been offset to lighten and more "pale" tone.
