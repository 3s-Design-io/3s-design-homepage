Why

Mic On Project ?

This is the Official Website design for Mic On Project. This is the first time we try to make the Horizontal scrolling website. It is both a unique and deep impression. In the construction of this website, the main user journey is to check the Mic On group and its talent's information, and next will be an auto-updated online live stream schedule viewer.

Graphics style and Color tone.

In this website design, It is important to try to make it less informational and make it attractive to keep going and reading on. The color tone is basic on the new Mic On branding and the 2+1 talents' main color, but the original color is way too strong and bold, the new color set has been offset to lighten and more "pale" tone.
